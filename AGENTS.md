# Repository workflow

The owner prefers direct commits to `main` for authorized implementation and release work. Do not create a pull request unless the user explicitly asks for one.

The public app name is **3£**. When the owner writes "3e", they mean **3£**. Use **3£** in menus, version labels, app metadata, executable names, shortcuts, and release titles.

Run the relevant checks before pushing. When asked to update the installed app, verify the published release and the version actually running on the destination computer.
