# 3£ logo

`3E-butterfly.svg` is the master mark: a **3** and a **£** set back to back, tops swung up and out and bottoms swung down and out, so the pair reads as a butterfly. Black and white only.

After changing the SVG, run `python3 Shared/Brand/make-icons.py` (needs Pillow). It regenerates the Mac app icon (`StripIcon.icns`, `3E.icns`), the Windows exe icon and tiles, and the small PNGs embedded in the Windows tray icon, the Clicks tray icon and the Mac menu bar (`ThreeEBrand.h`).
