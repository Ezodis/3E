# Strip3£ rebuild

This is the source-controlled rebuild of the macOS Strip3£ Touch Bar app.
The installed app at `/Applications/Strip3£.app` is deliberately not modified
by this project until the replacement is built and verified.

The first implementation milestone is three independent keyboard instances in
one Touch Bar. Each slot persists its own name, MIDI channel, base note,
transpose, octave range, and velocity, so the three keyboards can be mapped
differently.
