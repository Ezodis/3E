# Recovered working Strip3£ app

This bundle is the byte-for-byte recovered working app from the iCloud Drive archive. It is kept in source control as a recovery baseline while the editable implementation is rebuilt. It is not installed automatically; the canonical installed app is `/Applications/3£.app`. The folder is named `Strip3£-base` (no `.app` extension) so macOS does not register this old copy as a second app with 3£'s bundle ID, which made System Settings › Accessibility list 3£ as "Strip3£.app".
